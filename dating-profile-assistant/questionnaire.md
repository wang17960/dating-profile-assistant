# 渐进式画像问卷

本文件是题库，不是一次性问卷。每轮挑 3–8 个与当前目标相关的问题；用户已给出的答案记入 Profile，不重复问。允许跳过、不确定、不想回答、其他。问隐私资料时明确说明可只供分析、不写进公开文案。

## 模式与取题

- 快速写帖：基础公开资料、生活细节/兴趣、几项自我描述或他人反馈、择偶底线、平台和写作参数。只问成稿真正缺少的信息。
- 标准画像：再补社交、工作节奏、沟通与陪伴、冲突、家庭婚育、未来规划和正反向偏好。
- 深度探索：围绕用户在意的困惑分支，优先用情景题。若回答已经稳定清晰，不为覆盖题库而追问。
- 用户不确定某模块时，先给选择清单或近期具体例子，再询问“哪项最像你 / 哪项不像你”。

## 1. 基本资料与公开边界

1. 希望帖子用什么称呼或视角？（可不写性别）
2. 年龄或年龄段？
3. 常住城市、可接受的交往半径？
4. 籍贯是否对匹配重要？
5. 学历或在读状态希望怎么表述？
6. 职业、行业、工作性质分别是什么？公开时可用行业概述。
7. 工作稳定性、作息、加班或出差情况？
8. 收入、住房、车辆等信息是否有必要谈？选择：只供分析 / 模糊表述 / 可以公开 / 不讨论。
9. 婚史、子女情况是否为必要筛选信息？希望怎样表达？
10. 哪些资料绝对不进入公开内容？哪些只有匹配后再说？

## 2. 外形与自我管理

15. 熟人通常会怎么描述你的外形或气质？不想谈可跳过。

## 具体情景分支：我不确定

### 不确定性格
请用户回想最近一次聚会、计划变化、朋友求助、工作压力、独处周末；问其实际做法与别人反应，不推导固定人格标签。

### 不确定联系/陪伴需求
比较以下情境：一天忙到只简单问候；周末各自安排；对方临时取消见面；对方连续数小时未回复但提前告知；下班后每天见面。问哪个最舒服、哪个最难受及原因。

### 不确定冲突模式
让用户想象“对方批评了一件你在意的事”。提供暂停、马上解释、先确认情绪、独处整理、请求以后再谈等选项，再问何种修复方式有效。

### 不确定表达/接受关爱
分别让用户选择自己最近实际做过的关心行为，以及哪种伴侣行为让自己最有被在意感；不假定两者相同。

### 不确定未来或婚育
允许回答“目前倾向 / 尚未决定 / 需要具体条件才判断”。澄清伴侣间何时需要谈清，而非催促给确定答案。
