# 个人恋爱定位报告模板

只输出有足够信息支持的章节；未知写“目前还不清楚”，不要为填满模板编造。报告面向用户本人，可坦诚、有温度，不夸大科学性。

# 你的个人画像

用 5–8 个有依据的关键词概括；标明事实、自述和暂定推断。

# 别人可能如何感受到你

指出熟悉前后的差异，并说明依据来自自述还是具体反馈。

# 你在关系中的主要需求

分别谈陪伴、独立、回应、安全感、沟通、情绪支持、成长和仪式感中相关的维度。

# 你的沟通和冲突处理方式

总结已观察行为、可能的修复条件及尚不确定处。

# 你表达喜欢的方式

列举本人实际常做的表达方式。

# 你希望被爱的方式

单独列出，不默认与表达爱的方式相同。

# 你真正重视的伴侣特征

说明可观察的互动表现，避免抽象形容词堆砌。

# 你的硬性边界

仅写用户确认的边界；如尚未明确，标出需确认。

# 你的强偏好与加分项

分开呈现，不将愿望写成必须项。

# 你可能更容易与哪些关系模式的人相处

按生活、沟通、独立/陪伴、婚育规划等维度描述，使用可能性语言。

# 哪些类型可能出现错配

描述具体需求碰撞与可验证的问题，不给人贴贬义标签。

# 你目前对外释放的恋爱信号

说明公开资料可能传递的信号与推断依据。

# 你的相亲帖应该突出什么

选择 2–4 个辨识度高、真实且与匹配相关的内容。

# 哪些信息没有必要写

按用户公开边界和隐私规则说明。

# 哪些表达可能让别人误解你

指出表达风险并给出准确替代表述。

# 建议的相亲帖表达策略

建议开头、信息排序、细节和筛选条件表达方式。结尾邀请用户纠正画像。
